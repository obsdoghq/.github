## Observable Docs for humans and AI

ObsDog helps people and AI find, use, evaluate, and maintain knowledge. It keeps retrieval, exposure, selection, use, and usefulness as separate observations, so you can see what helped without guessing from a view count.

The local-first CLI searches Markdown, preserves document and block revisions, and records evidence about how knowledge is used. Optional hosted Personal sync is separate from local use.

## Get started

**Free local CLI beta · Apple silicon macOS.** No account is needed for local use. With Homebrew:

```sh
brew install obsdoghq/tap/obsdog
obsdog version
```

For a standalone installer or the combined CLI + Codex / Claude Code setup, see the [official installation guide](https://github.com/obsdoghq/obsdog-releases). The [agent setup guide](https://github.com/obsdoghq/skills/blob/main/docs/SETUP.md) explains how to use ObsDog in an existing agent workflow.
